# Render Marketing Audit

A full marketing overhaul audit of the Render site, run 2026-07-08 across every marketing skill available. Five specialized agents ran in parallel, one per skill cluster, each grounded in a shared brief containing the verbatim current site copy, the JSN competitor profile, and the business context.

## Start here

**[`00-executive-summary.md`](00-executive-summary.md)** - the top-level read. Includes the first-person "what would sell me as your customer" walkthrough, the competitive scorecard, and the consolidated P0/P1/P2 priority list. If you read one file, read this.

## The five detailed reports

| # | Report | What's in it |
|---|---|---|
| 01 | [`01-competitive-benchmark.md`](01-competitive-benchmark.md) | 8 live agency sites benchmarked + JSN. Where Render wins/loses, the service-menu decision (reposition, don't expand), comparison-page strategy, and a Morris County customer profile. |
| 02 | [`02-cro-conversion-audit.md`](02-cro-conversion-audit.md) | **Flagship.** The offer-ladder fix for the Calendly-only funnel, a page-by-page teardown with exact copy fixes, the missing-persuasion checklist, a prioritized CRO backlog, and a 5-test A/B plan. |
| 03 | [`03-copy-messaging-positioning.md`](03-copy-messaging-positioning.md) | Positioning statement, 5 hero rewrite options, a full fluff-sweep table (every weak line quoted + replaced), value-prop rewrites, pricing presentation, objection copy, and a paste-ready messaging one-pager. |
| 04 | [`04-seo-content-discovery.md`](04-seo-content-discovery.md) | Technical + local SEO audit, the recommended site architecture (hub + service pages + town pages), programmatic-SEO plan with anti-thin-content guardrails, AEO/AI-search plan, schema roadmap, 10-title content plan, and a GA4 measurement plan. |

`_brief.md` is the shared grounding doc the agents worked from (site copy, pricing, positioning, competitor snapshot). Kept for reference.
