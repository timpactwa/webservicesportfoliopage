## Current Recommendation Summary

Positioning:

- Lead with local business outcomes, not with being student-run.
- Use the founder story as a trust and pricing explanation.
- Say "lean founder-led team" more often than "student-run agency."

Pricing:

- Current pricing is probably too low long term.
- It can work as founding-client pricing if framed intentionally.
- A `$500` minimum is acceptable for the right proof-of-concept client.
- Raise prices as soon as there are real examples, testimonials, and a repeatable process.

Turnaround:

- Publicly promise 2-4 weeks for most website projects.
- Internally aim for 1 week of focused development on simple sites after intake is complete.
- Add more time for automations and client review.

Sales:

- Start with personalized email plus follow-up calls.
- Track everything in a simple lead sheet.
- Do not send generic mass outreach without a specific observation.
- Start with Randolph Local businesses that have no website listed.

Payments:

- Start with Stripe Payment Links after the call.
- Add website checkout later only if packages become standardized.

AI automations:

- Do not force automations into every website package yet.
- Include a light automation opportunity review with website projects.
- Sell simple automations as add-ons or standalone proof-of-concept projects when the pain point is clear.

Maintenance:

- Keep maintenance optional and affordable at first.
- Include hosting, small edits, basic reports, and on-site tweaks.
- Start at `$50/mo` for founding clients.
- Internally define a time boundary so maintenance does not become unlimited project work.

Automation:

- Design the business process as if it will be automated.
- Run it manually first.
- Automate only after the pattern is proven.

Follow-up:

- Revisit this strategy in 2-3 weeks after initial outreach and project planning.
